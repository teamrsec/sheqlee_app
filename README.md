# Sheqlee App - Flutter Freelance Platform  

🌟 **Sheqlee** is a Flutter-based mobile application designed to bridge the gap between skilled programmers and companies looking to hire top talent. It provides a seamless platform for freelancers to showcase their skills and for employers to find the right talent for their projects.  

---

## **Features**  

### **For Freelancers**  
- Create a detailed profile showcasing skills, experience, and portfolio.  
- Browse and apply to job postings tailored to your expertise.  
- Communicate with employers via real-time chat.  
- Manage projects with built-in task tracking and milestone tools.  
- Receive secure payments upon project completion.  

### **For Employers**  
- Post job listings and search for skilled freelancers.  
- Use AI-powered smart matching to find the best candidates.  
- Track project progress and communicate with freelancers.  
- Rate and review freelancers to build a trusted community.  

---

## **Tech Stack**  

- **Frontend**: Flutter (iOS & Android)  
- **Backend**:Node JS  
- **Database**: MongoDB (NoSQL)  
- **AI/ML**: TensorFlow (for smart matching algorithms)  
- **Additional Tools**: Python (backend scripts), SQL (analytics)

## **Installation**  

1. Clone the repository:  
   ```bash  
   git clone https://github.com/your-username/sheqlee-app.git  
   ```  
2. Navigate to the project directory:  
   ```bash  
   cd sheqlee-app  
   ```  
3. Install dependencies:  
   ```bash  
   flutter pub get  
   ```  
4. Run the app:  
   ```bash  
   flutter run  
   ```
